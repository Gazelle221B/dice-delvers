# プール制の非活動手番、探索 CPU、単独変種の比較

## 貪欲同士の非活動手番

各陣営 2,000 試合、シード 0..2000。区分は手番側を基準とする。非活動は召喚・移動・攻撃宣言がすべて 0 の手番。Wings の使用だけなら非活動で、使用前後の合法機会を拾う。移動先は合法な停止位置。対象は移動前の位置から攻撃できる相手で、ウォーデンからの攻撃も含む。移動と攻撃の不足は同時に起こるため、両者を交差させて二重計上を防ぐ。

| 陣営（先–後） | 初召喚前・自駒なし | 初召喚後・自駒なし | 移動不足＋攻撃対象なし | 移動不足＋攻撃不足 | 移動可＋攻撃対象なし | 移動可＋攻撃不足 | 非活動 / 全手番 |
|---|---|---|---|---|---|---|---|
| ember-frost | 2851 | 62 | 1033 | 330 | 1750 | 514 | 6540 / 27834 (23.50%) |
| frost-ember | 2851 | 46 | 1051 | 324 | 1660 | 458 | 6390 / 27146 (23.54%) |
| ember-ember | 2851 | 41 | 806 | 345 | 1585 | 631 | 6259 / 26537 (23.59%) |
| frost-frost | 2851 | 32 | 1408 | 299 | 1843 | 367 | 6800 / 28897 (23.53%) |

最多は全陣営で初召喚前の自駒なし。Ember–Frost は 2,851 / 6,540（43.59%）。自駒が生存する 3,627 手番では移動の見送りが 2,264（62.42%）、移動ルーン不足が 1,363。見送りには横移動や後退も含む。貪欲は敵ドメインに近づく移動だけを選ぶ。合法な攻撃を見送った非活動手番は 4 陣営計 0。自駒なしでもウォーデンは攻撃できる。通常陣営の初召喚前 12 手番と初召喚後 11 手番では相手が隣接していたが攻撃ルーンがなかった。

各陣営の初召喚前 2,851 手番の最終出目を調べると、2,850 手番で同レベルの召喚ペアが成立せず、1 手番だけは成立してもタイルを置けなかった。Ember–Frost の例はシード 1381 の第 25 手番（P1）。初召喚後に自駒が全滅していた非活動手番では、4 陣営とも召喚ペアは 0 件だった。

## 対貪欲の検定

探索は貪欲手、レベルを揃えるロール、召喚、前進・迎撃・配置などの候補を比較する。候補間で共通の仮想シード 6 本から最大 8 手番を貪欲同士で進め、勝敗・LP・敵ドメインへの接近と隣接・生存戦力で採点する。方策乱数は !seed、実ダイスは seed。探索局面のダイス乱数は仮想シードで初期化する。方策の決定後に、開発用と分離した連続する 4 区間を測定した。

### 変更ごとの読み方

- **pool** は探索同士でも両陣営で先手が勝ち越した。Ember の 95% 区間は 50% を上回り、Frost では 50% を含む。同じ 0..500 に絞った貪欲の先手勝率は Ember 56.20%、Frost 51.60%、非活動率は 23.82%、24.36%。探索の非活動率はそれぞれ 26.71%、32.24% で、同じシードでも高い。探索同士で合法な攻撃を見送った非活動手番は Ember 424、Frost 954。
- **後手の移動ルーン**で先手勝率の点推定は全構成で 50% に近づいた。Ember 貪欲だけ 49.35% まで下がった。4 構成とも変更後の勝率区間は 50% を含み、探索の対応差の区間には 0 も入る。Frost の席平均召喚の差は貪欲 −0.06、探索 +0.08。Ember の非活動率の微差も方策間で逆向きだが、どちらも 0 と整合する。
- **先手初手 2 個**では 4 構成すべてで先手勝率が下がり、点推定は 50% を割った。Ember 貪欲の 45.20%［43.03–47.39］は明確に後手側へ行き過ぎた。他の 3 構成は 50% を含む。初召喚前の非活動は両方策で増えた。Frost の総非活動率と平均手番については貪欲で増、探索の点推定では減で、探索側の差の区間は 0 を含む。
- **振り直し**で全構成の非活動率が 3.91–8.10 pt 下がった。初召喚前の非活動は、貪欲では両ミラーとも 2,851 → 1,530、探索では Ember 742 → 605、Frost 638 → 597。平均は 1.32–2.44 手番短く、貪欲の中央値は両ミラー 11、探索は 13 と 14。望ましい試合長は今回の実験では定めていない。Frost の先手勝率差は貪欲 +1.30 pt、探索 −2.60 pt で、両区間とも 0 を含む。
- **LP 5**では全構成で平均 4.94–6.66 手番長くなり、召喚は席平均で 1.02–1.07 体増えた。15 個中の終局時の残りは席平均 9.87–10.76 個。LP 3 の早期決着はプール消費を抑える要因の一つだが、LP 5 でも平均して過半のダイスが残った。Ember の先手勝率差は両方策で負。Frost は貪欲 +0.30 pt、探索 −1.60 pt でどちらも 0 と整合する。

自由枠は使わなかった。最多の初召喚前の失敗は振り直しで、合法移動の見送りは方策の比較で直接調べられる。実験プリセットだけを追加し、既定の決定や対人戦での効果判定は今回の範囲に含めていない。

## 既存プリセットの互換性

PR #8 の 572316a と同一の Rust 1.94・fastrand で、先後の陣営 4 組 × 貪欲・ランダムの方策 4 組 × シード 0..2000 を比較した。試合ごとに初期値をリセットした FNV-1a 64 bit で、全行動、毎ロール直後の出目、終局結果・理由・手番・LP・ルーン・ユニット・盤面、ログ各行を順にハッシュ化。両版の 32,000 行を各プリセットで cmp した。各 16 構成とも 2,000 / 2,000 一致。試合別ハッシュ一覧の SHA-256 は basic が `5827484571bc28a6516482fae46dadb961acc2c0810a70ae12bf9aec6f2b9b32`、pool が `90b914c556744edea3369502b8e77a5c9e2181dc0174f9e77343540b3603fc4c`。

## 再現手順

```sh
export CARGO_TARGET_DIR="$PWD/target/sim"
cargo build --release -p delvers-sim
sim="$CARGO_TARGET_DIR/release/delvers-sim"
for f in ember-frost frost-ember ember-ember frost-frost; do
  "$sim" 0..2000 greedy greedy "$f" pool
done
"$sim" 10000..11000 tactical greedy ember-ember pool
"$sim" 11000..12000 greedy tactical ember-ember pool
"$sim" 12000..13000 tactical greedy frost-frost pool
"$sim" 13000..14000 greedy tactical frost-frost pool
for f in ember-ember frost-frost; do
  for r in pool p2-move opening-two reroll lp5; do
    "$sim" 0..2000 greedy greedy "$f" "$r"
    "$sim" 0..500 tactical tactical "$f" "$r"
  done
done
```

対応差や 300 手番を除いた参考値を再集計する際は、同じ CLI に各シードを「開始+1」で渡すと、集計前の 1 試合分の手番数・非活動数・勝者・召喚数を得られる。
